# Condiciones del servicio: decisiones del titular y detalles pendientes

Este documento registra las instrucciones del titular. Es un borrador de oferta, no un contrato final ni una ampliación del servicio por recomendaciones del PDF.

## Confirmado

- Creación de una web por **99,99 €, pago único con IVA incluido**. Se conserva la posibilidad de financiar en tres meses ya confirmada; no se han definido proveedor, intereses ni calendario de cuotas.
- Orientación de **cinco a diez páginas**, con posibilidad de más según el negocio. La estructura se acuerda antes de empezar; no es una promesa de páginas ilimitadas ni justifica páginas SEO repetitivas.
- Contacto por WhatsApp y llamada cuando el cliente quiera esos canales. Sin compra ni pago online en esta oferta.
- Pymes Control redacta los textos después de hablar con el responsable, conocer su negocio y definir a qué público quiere atraer.
- El cliente aporta las fotografías, preferentemente reales y autorizadas. Se pueden acordar ilustraciones con IA; se identifican cuando puedan confundirse con fotografías de instalaciones, productos, equipo o trabajos reales. No se crean pruebas falsas de experiencia.
- El dominio lo paga el cliente por separado.
- Objetivo de entrega: una semana. Sigue pendiente el momento desde el que se cuenta y debe concretarse el alcance. El deseo de tenerla posicionada en una semana no se publica como garantía: ni la indexación ni las posiciones de Google tienen un plazo controlable por el proveedor.
- El servicio se paga desde el principio; no se ofrece un mes de prueba gratuita. El titular retira la política comercial de devolución durante un mes. No se publica una cláusula general de «sin devoluciones»: los derechos legales que correspondan no se eliminan con esta decisión comercial.
- Los cambios que el cliente no pueda hacer por sí mismo y encargue a Pymes Control son **gratuitos durante el primer mes**, contado desde que **tiene la web y ha pagado**.
- **Después del primer mes: 20 € más IVA por cambio** encargado a Pymes Control. El titular confirmó expresamente que ese importe no incluye IVA. Se acuerdan alcance e importe total antes de realizarlo. Si se aplica IVA del 21 %, el total es 24,20 €; no se presupone un tratamiento fiscal idéntico para todas las operaciones.
- La edición por el propio cliente y un encargo de cambios a Pymes Control son acciones diferentes. La tarifa de asistencia no se aplica automáticamente a ediciones que el cliente haga por sí mismo. No se ha confirmado el precio de posibles servicios de terceros.

## Alojamiento: comprobar el servicio que ya se utiliza

El titular quiere que el cliente no tenga cuota de alojamiento mientras el servicio utilizado sea gratuito. No se promete gratuidad perpetua ni se fija un cargo futuro sin acuerdo.

Se comprobó la documentación oficial de GitHub Pages en el [repositorio de GitHub Docs](https://github.com/github/docs/blob/main/content/pages/getting-started-with-github-pages/github-pages-limits.md), correspondiente a [GitHub Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits). Indica que Pages no está destinado ni permitido como alojamiento gratuito para operar negocios online, sitios de comercio electrónico o sitios principalmente orientados a facilitar transacciones comerciales o prestar SaaS.

El titular indica que su web está en GitHub. GitHub puede guardar el código y GitHub Pages puede servir la web al público: son funciones distintas. «Proveedor de alojamiento» se refiere al servicio técnico que sirve la web, no a un banco ni a una obligación del cliente de contratar otro servicio. Primero debe comprobarse cómo se aloja la web actual y si sus condiciones permiten el uso previsto. Solo si fuera necesario se estudiaría un cambio; no se ha contratado ni cambiado alojamiento. La ausencia de pago online no elimina automáticamente la restricción de Pages.

## Detalles pendientes de concretar

1. Alcance de cada encargo de cambio, que se acuerda antes de realizarlo; no se prometen ampliaciones ilimitadas.
2. Inicio de la semana de entrega y significado de «ha pagado» para iniciar el mes de cambios cuando se financie el importe.

## Identidad del vendedor, factura y público objetivo

El vendedor es quien cobra los 99,99 €: el titular como profesional o su empresa. Tras aclarar la identificación legal, el titular ha autorizado incorporar el nombre Francisco Vargas y el NIF que facilitó. Están en `content/legal.json` y en el borrador `aviso-legal.html`, enlazado desde el pie; el NIF no se reproduce en las páginas comerciales. Falta el domicilio profesional y el documento sigue marcado como borrador. Se comprobó la letra de control del NIF; esta operación no verifica identidad, alta fiscal ni alta como autónomo.

Para una actividad comercial en España, el artículo 10 de la LSSI establece deberes de identificación, incluido el NIF. La emisión de facturas tampoco debe condicionarse únicamente a que el cliente las solicite: se concretarán las obligaciones aplicables a la actividad. Referencias: [LSSI, artículo 10](https://www.boe.es/buscar/act.php?id=BOE-A-2002-13758#a10) y [Reglamento de facturación, artículo 2](https://www.boe.es/buscar/act.php?id=BOE-A-2012-14696#a2).

Los datos del comprador necesarios para su factura son otra cuestión. No se solicitan datos fiscales sensibles en las páginas de captación actuales.

El buyer persona es el público al que el negocio del cliente quiere vender. Se investiga en la conversación de preparación y orienta textos y estructura; no sustituye los datos fiscales del vendedor ni del comprador.

## Aplicación a la web

Se incorporaron a servicio y proceso los puntos claros: tamaño orientativo, contactos opcionales, ausencia de compra online, redacción tras entrevista, fotografías, dominio aparte y plazo objetivo sin garantía de posicionamiento. Se retiró la política comercial de devolución y se incorporó la condición aclarada: cambios gratuitos durante el primer mes desde entrega y pago; después, 20 € más IVA por cambio encargado. El alcance de cada cambio se acuerda antes de realizarlo. La integración de edición sigue pendiente de implementación y prueba. La web conserva noindex.
